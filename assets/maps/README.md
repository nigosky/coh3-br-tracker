# Miniaturas Oficiais de Mapas — Company of Heroes 3

Contém 76 miniaturas táticas oficiais dos mapas do Company of Heroes 3 (atualizadas até o Patch 3.0.0 e modo Final Stand), extraídas do repositório público [`cohstats/coh3-cdn`](https://github.com/cohstats/coh3-cdn) (`coh3stats.com`) e otimizadas em formato PNG local (128px preservando proporção original) para renderização offline segura (`formats=["PNG"]`) sem dependências de rede em tempo de execução.
